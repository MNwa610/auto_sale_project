# Веб-интерфейс автосалона

Для локального запуска нужен Node.js 20.19+ или 22.12+ и работающий [backend](../backend/README.md) с БД КР3.

Из папки `frontend`:

```sh
npm ci
npm run dev
```

Откройте адрес Vite (обычно `http://localhost:5173`). Vite пересылает `/api` в `http://localhost:8080`. Для другого адреса backend задайте `BACKEND_URL` в окружении или в `.env.local`.

- `npm test` проверяет клиент REST API.
- `npm run build` собирает `dist/`.
- `npm run preview` запускает локальный предпросмотр сборки с той же настройкой прокси.

При размещении сборки направьте `/api` с того же origin на backend. Сессия хранится в памяти вкладки, поэтому после перезагрузки страницы нужно снова войти. Ротация refresh-токена используется для восстановления активной сессии. После конфликта версии загрузите актуальные данные и повторите изменение.
