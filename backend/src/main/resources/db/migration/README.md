# Миграции PostgreSQL

Миграции применяются Flyway при запуске backend в отдельной БД КР3:

- `V1` — схема на основе КР1: автомобили, пользователи, справочники, заявки, теги.
- `V2` — таблицы для refresh-сессий, попыток входа, заметок, аудита и CSV-сессий.
- `V3` — роли `VIEWER`, `MANAGER`, `ADMIN`, без пользователей и паролей.
- `V4` — семейства refresh-сессий для ротации и отзыва при повторном использовании.

Hibernate использует `ddl-auto=validate`, SQL-инициализация Spring отключена.
Автоматический baseline и Flyway clean отключены. Непустая чужая схема без
истории Flyway не принимается автоматически.

Не копировать сюда `database.sql` из КР1 без переработки: он удаляет таблицы.
После применения миграции изменения схемы оформляются новой миграцией.
