# Состояние КР3

Работа ведётся в существующей ветке `main`. Коммиты, push и merge выполняет
пользователь. Каждый следующий этап начинается только по его команде.

## Этап 0 — аудит

Изучены требования КР3, схема `database.sql`, тег КР1 `kr1-final`, JavaFX-клиент,
JDBC-репозитории, сервисы и тесты КР2. Полный аудит и план представлены в чате.
На этапе аудита исходники не изменялись.

## Этап 1 — каркас backend

Область: отдельный Maven-проект `backend/`, Java 21, Spring Boot, REST,
валидация, единая обработка ошибок, Swagger/OpenAPI, Actuator health,
контекстные и HTTP-тесты, инструкции запуска.

КР2 сохраняет собственные `pom.xml`, `src/` и способ запуска JavaFX.
Бизнес-сущности и схема БД на этапе 1 не изменяются. PostgreSQL, Flyway,
Hibernate, JWT, роли, frontend и Docker ещё не реализованы.

Общие файлы команды: `backend/pom.xml`, `backend/src/main/resources/application.yml`,
общая обработка ошибок и OpenAPI-конфигурация. У каждого должен быть один
ответственный. Проверки и документацию можно распределить отдельно от каркаса.

Критерии готовности: `mvn -f backend/pom.xml clean verify`, проверка запуска
исполняемого JAR и доступности `/api/v1`, `/actuator/health`, `/swagger-ui.html`,
`/v3/api-docs`; отдельная сборка КР2; сохранение пользовательских правок.
